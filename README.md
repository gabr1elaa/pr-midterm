# Network Programming Midterm – practice quiz

Practice quiz for the Network Programming course (UTM), Lectures 1–5:
concurrency and multithreading, shared state / races / locks, async / queues / cancellation,
TCP sockets, JSON and XML.

**Open it:** https://gabr1elaa.github.io/pr-midterm/

- 185 multiple-choice and true/false questions, including all questions from the previous quizzes
- Practice mode with instant feedback, explanations and the slide each answer comes from
- Timed mock midterm with a score per lecture and a full review
- 78 definitions from the lecture slides, searchable

Your answers are saved in your own browser only.

Based on the lecture slides and the code in
[Network_Programming_Course](https://github.com/Ernest96/Network_Programming_Course).
